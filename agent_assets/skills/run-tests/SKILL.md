## 什么时候用
用户明确要求测试或定位测试失败时使用；闲聊和解释语法不触发。
## 步骤
1. 读取项目规则和测试入口，确定正确的工作目录。
2. 用 bash 执行最小相关测试，优先 `python -m unittest discover -s tests -q`；项目已有 pytest 时可用 `python -m pytest -q`。
3. 核对真实退出码，只整理最多三个失败用例。命令失败和断言失败分别说明。
4. 每个失败只回用例、期望、实际；这个技能只做验证，不顺手修复。
5. 没有测试或依赖时明确说明未完成验证，不把零用例当成功。
## 不要做什么
- 不修改测试期待值以掩盖失败，不报告未执行的测试。
## 怎么算做完了
- 已报告执行命令、退出码、通过与失败数量以及失败摘要。
