# CodeDesk Windows 签名版

在桌面设置中选择 DeepSeek 或其他兼容服务，输入模型、服务地址和自己的 API Key。Key 不需要写进源码。

本发布脚本仅在以下检查全部通过后上传附件：应用及 MCP 的所有原生程序签名、安装器及安装临时组件/卸载器签名、可信时间戳、安装后文件一致性、独立启动、界面资源、示例项目、真实 MCP 子进程调用、卸载，以及便携包完整性。

附件包含完整安装包、完整便携目录压缩包、签名清单、安装验收记录和 SHA256 校验值。验收记录对应安装包的 SHA256。安装包使用当前用户安装方式，不需要管理员权限。运行原生界面需要 Microsoft Edge WebView2 Runtime。

自动验收不包含真实模型付费调用、所有 Windows 策略的兼容性、原生窗口的人工操作或杀毒厂商的误报排除。签名不保证所有设备放行，学校管理的电脑仍应遵循设备管理规则。模型调用请在桌面配置自己的有效 Key 后测试。
