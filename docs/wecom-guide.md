# CodeDesk 企业微信任务中心使用说明

**版本 1.4.1 · 沐光小组课程项目 · Windows x64**

本版从指定提交包内的 1.3.1 源码继续开发。电脑负责执行，企业微信机器人单聊负责接收要求、反馈状态和交付文件。课堂演示使用同一套界面与任务执行器，可在没有机器人帐号和模型 Key 时操作。

## 跟着视频完成第一项任务

1. 完整解压交付包。进入 `02_Portable/CodeDesk`，双击 `Start-Demo.cmd`。保留命令窗口，浏览器先打开原来的 CodeDesk 代码工作台。点击右上角「微信任务中心」，黄色横幅标明当前使用演示环境。点「返回代码工作台」可继续刚才的编辑。
2. 在「任务工作台」保留身份 `owner` 和「演示项目」。点击「附件」，选择交付包 `04_Guide/wecom-demo.csv`。发送「暂存 检查三个题项的 TV，生成中文报告」。材料和要求会留在草稿中。
3. 发送「开始」。记下任务编号，在详情里追加「以基线 TV 减去方法 TV，正值表示改善」，再点「批准执行此任务」。
4. 等到状态变为「已完成」，点击「实验检查报告.md」。报告读取了上传的三行数据。a33、a36、a17 的改善值依次为 0.13、0.12、0.10，算术平均值为 **0.1167**。这些数字来自随包样例。

| 启动入口 | 何时使用 |
|---|---|
| `Start-Demo.cmd` | 独立的临时项目和预设模型。适合复现视频和演示 CSV 示例。关掉命令窗口结束本次演示。 |
| `Start-CodeDesk.cmd` | 正式桌面工作台。在「模型与连接」配置模型服务后，可处理自选项目。运行时需 Windows x64 和 Edge WebView2。 |
| `01_Installer` | 提供同版未签名安装程序。安装后从开始菜单打开 CodeDesk，也可打开 CodeDesk Demo。 |

## 连接自己的企业微信机器人

1. 准备支持 API 模式长连接的企业微信智能机器人，并取得 **BotID、Secret 和允许成员的 UserID**。成员身份使用企业微信帐号标识。
2. 在正式桌面工作台右上角进入「微信任务中心」→「连接与身份」。保存允许的 UserID，再填写 BotID 和 Secret，点击「连接企业微信」。看到「企业微信已连接」表示订阅已收到成功回执。Secret 只用于本次连接，重启后重新输入。
3. 在「项目与规则」登记项目别名、已有文件夹的绝对路径和规则。首次可选「只读问答」。需要产出文件时选「修改与命令」，每项任务单独批准。该模式可以在当前 Windows 用户权限下运行命令。
4. 保持电脑在线、应用运行。进入机器人的**企业微信单聊**，先发「项目」，再发「切换 课程项目」（替换为实际别名）。发送单独的 CSV 或图片并等候暂存回复，然后发送任务要求。多个要求可用「暂存」分条收集，最后发「开始」。

| 在单聊中发送 | 应观察到的结果 |
|---|---|
| `任务` 或 `状态 任务编号` | 最近任务列表，或指定任务的状态和结果摘要。 |
| `补充 任务编号 新要求` | 只读任务在下一轮模型调用前读入。待执行的修改任务须重新批准。已在执行的修改任务可取消后重新提交。 |
| `批准 任务编号`、`暂停 任务编号`、`继续 任务编号`、`取消 任务编号` | 按当前状态处理。暂停在执行轮次之间生效，等待时间计入任务总超时。 |
| `文件 任务编号`，随后 `取件 任务编号 1` | 先返回产物序号，再上传对应文件并发送到本人单聊。桌面可在「交付记录」查看回执。 |

附件支持 TXT、Markdown、CSV、JSON、PDF、DOCX 和常见图片。每个草稿最多 8 个附件、单个 8 MiB。图片、文件与文字请分条发送。电脑需能访问企业微信的长连接和媒体服务；模型服务凭据在桌面「模型与连接」单独配置。

## 实现与验收范围

| 环节 | 实现与验证方法 |
|---|---|
| 消息接入 | `agent/wecom.py` 处理订阅、回执、心跳和重连。只接受已登记成员的单聊。相同来源、身份和消息编号共用一次处理结果，保留最近 5,000 条去重记录。 |
| 任务执行 | `agent/remote.py` 在 SQLite 保存任务、草稿和交付状态。提交时固定目录、模式和项目规则。桌面切换项目后，已提交任务继续使用原目录。远程任务使用现有执行器，独立于普通聊天历史，不加载桌面 MCP 服务。 |
| 文件交付 | `agent/wecom_media.py` 处理受信媒体域名、下载大小、解密及分片上传。取件前校验已登记文件的 SHA-256。任务完成与消息送达分开记录，重发交付消息不会重跑电脑上的任务。 |
| 浏览器实测 | 真实前端经进程内应用接口提交 CSV、批准任务并下载报告，实际触发 read 和 write。视频连续录制桌面页面，并打开下载内容。演示模型根据实际文件计算样例结果。 |
| 平台协议测试 | 内存中的对端模拟企业微信的消息帧和回执，覆盖订阅、接收附件、批准、主动回报和取件，核对收到的文件字节与本地报告一致。另测重复消息、身份隔离、取消、异常回执和重启状态。 |

**真机联调状态**　本次没有可用于实发的企业微信机器人凭据。需要用实际帐号核验租户权限、手机收到的任务回复、媒体下载域名和文件交付。视频中的「本地联调」与正式渠道有独立会话记录。普通微信个人号好友聊天不在此版本接入范围内。

**异常处理**　回执不确定时先查看单聊里是否已收到，再在桌面点击「核对后重发消息」。应用退出时正在执行的任务会标为中断；核对已生成的文件后可新建任务。后台接单要求电脑开机并运行 CodeDesk。同一个正式数据目录请只启动一个工作台实例。

**验收文件**　`04_Guide/validation.json` 记录本次回归、浏览器和便携运行时验收结果，1.3.1 原始报告与讲解稿在 04_Guide/1.3.1，原版两段演示在 05_Video。源码离线复测可运行 `python scripts/offline_validation.py unittest discover -s tests -q`，前端测试运行 `npm test`。

企业微信官方机器人 SDK 与长连接协议说明见 [WecomTeam/aibot-node-sdk](https://github.com/WecomTeam/aibot-node-sdk)。
