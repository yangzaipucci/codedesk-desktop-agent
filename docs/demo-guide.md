# 现场演示与常见抽查

先在老师电脑安装/启动，完整保留程序目录，在桌面接入有效模型 Key，选择新的项目文件夹。不要只展示 localhost 网页；使用带原生标题栏的 CodeDesk 窗口。

## 五分钟顺序

0:00–0:30 双击快捷方式，展示浅深主题、模型与工作目录。0:30–3:00 接收老师临时需求：关联文件→Agent/Debug→读文件→最小修改→真实运行检查。3:00–4:00 展示 edit 不唯一或文件不存在的失败，再读取更多上下文修正。4:00–4:40 调用外部 MCP 并指出来源。4:40–5:00 说明一个当前限制。

## 练习题（以实际工具结果为准）

- 解释陌生项目结构、找某个函数、全项目搜索调用位置；用 Ask 保持只读。
- 修复空输入、缺失文件、JSON 字段或文本编码问题；用 Debug 复现并运行相关检查。
- 新增函数/接口/小页面，并生成测试；确认新文件出现在文件树，中间能编辑。
- 改动后核对 diff、撤销一次，再故意手工改变文件验证冲突拒绝覆盖。
- 今天几号/星期几；南京或其他城市天气；公开网页查找；近几年某主题文献；计算带括号的表达式。
- 读取 PDF/DOCX 摘要：必须先关联项目内文档；扫描 PDF 应明确提示 OCR。
- Plan 先做方案不改文件，再点击执行；Multitask 加两个互不依赖任务，检查依次完成与单独取消。
- 运行一个耗时任务后点击中断；检查后续仍可提问，不能只让按钮变成停止状态。
- 关闭再打开：同一工作区最近普通会话恢复；保存过的 Key 由 Windows 凭据管理器复用。

## 答辩要点

edit 为什么唯一：避免把多个同样片段一起改错。连续重复怎么处理：同一名称与参数第 4 次阻止并停止。MCP 和内置如何路由：四内置固定名称，MCP 保存服务/原始工具映射，界面明确显示来源。联网不是靠猜：展示工具时间、URL、DOI 或真实命令输出。

Ctrl S 保存；Ctrl P/Ctrl K 快速打开；Ctrl Shift F 搜项目；Ctrl L 询问选区。拖动文件栏与对话栏分界线调整宽度，拖动终端上沿调整高度；双击分界线恢复默认。
