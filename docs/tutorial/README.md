## 演示范围与证据层级

展示技能目录与三种形态、同任务技能关闭/开启、执行前策略拒绝、实际测试红转绿、只读审查账目、常驻验收、新版设置与实际本机MCP调用。

模型决策使用明确标注的稳定受控Provider；文件操作、Git、测试、MCP和检查点恢复都是真实运行。危险请求只交给Hooks.before验证拒绝，不执行删除或强制推送。结果以程序生成的JSON为准，不把受控演示当成真实模型质量测评。

MCP HTTP默认地址为127.0.0.1:8001/mcp，需独立启动服务并使用MCP连接令牌；stdio不占TCP端口。实际演示的MCP成功为本机工具调用，飞书内容为配置参考，尚未授权真实飞书账号。用户凭据只在本人电脑输入。

现场仍使用安装后的桌面程序接受临场需求，视频仅作材料留档。

同目录旧版教程文件保留原位置供存档查阅；当前演示以编号2链接和对应validation.json为准。
