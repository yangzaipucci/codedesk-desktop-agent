# CodeDesk 1.1.0

新增浅深双色工作台（默认浅色）、可编辑多标签代码区、搜索/上下文/差异/终端、Agent/Plan/Debug/Multitask/Ask 模式，以及日期/天气/网页/文献/计算与 PDF/DOCX 阅读。

代码、命令与工具详情在中间查看，右侧保留结果；分栏与终端可拖动。重启恢复同工作区最近普通会话；队列上下文独立。

提供完整源码、离线前端、便携运行目录与按用户安装的 EXE。API Key 由用户在桌面填写，分发材料不含真实凭据。预览安装器名称明确带 unsigned；受信任签名流程保留独立门禁。

仓库：https://github.com/yangzaipucci/codedesk-desktop-agent

详细测试与真实 API 使用记录见 validation.md，构建见 build.md，现场抽查见 demo-guide.md。
