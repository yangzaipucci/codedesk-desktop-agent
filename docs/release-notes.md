# CodeDesk 1.0.0

Windows x64桌面编程智能体。下载CodeDesk-Setup-1.0.0.exe安装，双击打开后，在设置里输入自己的API Key、模型与服务地址。

功能包含三栏界面、read/write/edit/bash、分页读取、原子写入、精确替换、差异、命令输出、中断、用户撤销、多家兼容模型接口、真实MCP演示进程、预算与重复调用护栏。

修复新会话系统提示丢失，检测提前结束的模型流，避免截断参数被误执行，改进MCP发现失败清理和凭据删除错误反馈。

自动检查涵盖实际文件、命令和MCP外部进程。API适配器用受控响应验证，不冒充真实Key调用。模型联网验收需用户在桌面配置有效Key。安装包未使用代码签名证书，需要Microsoft Edge WebView2 Runtime。
